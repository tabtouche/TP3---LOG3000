# Flask Calculator

**Équipe 9** — Sarah Tabti, Tidiane Cissé, Yacine Makhlouf

## Objectif

Calculatrice web simple construite avec Flask. L'utilisateur saisit une expression à deux opérandes (ex. `7+3`) via l'interface, et le serveur calcule le résultat (addition, soustraction, multiplication, division).

## Prérequis

- Python 3.8 ou plus récent
- pip
- Git

## Installation

1. Cloner le dépôt :
```bash
   git clone https://github.com/tabtouche/TP3---LOG3000.git
   cd TP3---LOG3000
```

2. Installer Flask :
```bash
   pip install flask
```
